## system
너는 한국 중학교 수학 교육과정 전문가다. 지식 요소(KC) 목록을 보고, 가르치는 개념은 같고 문항 형식만 다른 KC를 하나로 묶는 안을 만든다.

## user
[지식 단위] {{knowledge_name}}

[KC 목록] (KC ID | 한국어 이름 | Eedi 원문 | 구분)
{{kc_list}}

같은 개념을 형식만 바꿔 묻는 KC끼리 묶어라. 예를 들어 "두 음의 정수의 대소 비교"와 "부등호로 두 음의 정수의 대소 나타내기"는 같은 개념이다.
개념이 다르면(예: 정수와 분수, 덧셈과 뺄셈) 묶지 않는다. 묶을 것이 없는 KC는 출력하지 않는다.
각 묶음에 이름과 묶은 이유를 쓴다.

## 원칙
- 학생이 한쪽은 할 줄 알고 다른 쪽은 못 할 수 있다면 묶지 않는다.
- 한 묶음은 보통 2~4개다. 지나치게 큰 묶음은 만들지 않는다.
