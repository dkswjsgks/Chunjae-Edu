# Q행렬 선정 기준 (실험 전에 확정)

## 1. KC 사전 (Q의 KC 열, 오개념 후보 범위)
| 지표 | 비고 |
|---|---|
| AFM AIC·BIC, 새 문항 예측 RMSE | 지식=KC, 토픽=KC 기준선보다 나아야 함 |
| 원래 KC vs 묶음 KC | 차이가 신뢰구간 안이면 묶음(단순한 쪽) |

## 2. Q 매핑 (세 버전 공통)
| 지표 | 비고 |
|---|---|
| 사람 검수 정확도 | 블라인드 2인 판정. 가장 직접적인 증거 |
| 오답 선지 예측(top-1, 로그우도) | 인기 선지·무작위 기준선 대비 |
| 반복률 | 같은 오개념 선지가 같은 학생에게 우연보다 자주 몰리는가 |
| 모델 간 일치 κ | 낮으면 오개념 정의 재검토 |
| 역산 재현율 | 계산 경로가 선지 값을 실제로 만드는 비율 |
| 해당 없음 비율 | 너무 높으면 사전 부족, 너무 낮으면 억지 매핑 의심 |
| KC 부분집합 위반율 | 오답 선지 KC가 정답 선지 KC를 벗어난 비율 |
| 취약 KC 예측 | Q의 KC 열로 추정한 숙달이 평가용 문항 정오답을 예측하는가(AUC, 로그우도). 2단계 문항 KC 배정만 쓴 AFM이 기준선 |

## 3. 세 버전을 같은 기준으로 비교하는 방법
세 버전 모두 "선지 행 × (KC + 오개념) 열"의 가중치로 바꿔 **같은 예측기, 같은 분할, 같은 지표**에 넣는다(2절).
- 가중치: 버전1은 0/1, 버전2는 점수, 버전3은 1 → 1, 0과 무관 → 0
- 오답 선지 예측: 학생 오개념 점수 = Σ(고른 선지 행의 오개념 가중치)
- 취약 KC 예측: 학생 KC 점수 = Σ(고른 선지 행의 KC 가중치)를 선지 수로 나눈 값
- 사람 검수·반복률·모델 간 일치: 상위 1개 오개념 기준

버전마다 다른 것은 **보조 지표**로만 쓰고, 공통 지표 차이가 신뢰구간 안일 때 판단 근거로 쓴다.
- 버전2만: 상위 k개 순위 품질(MAP@k), 확률 보정
- 버전3만: 0 판정의 정확도(사람 검수), GDCM-MC 적합
- 선지 단위 진단 모형 적합: 버전1은 그대로, 버전2는 임계값으로 이진화해서. T샘 문항 정보를 받으면 진행(보류)

## 4. 선택 규칙
1. KC 사전이 기준선보다 낫지 않으면 KC 크기부터 다시 정한다
2. 사람 검수 정확도가 기준(예: 70%) 미만인 후보 제외
3. 남은 후보 중 오답 선지 예측·반복률이 가장 좋은 것. 차이가 신뢰구간 안이면 단순한 쪽(이진 > 확률 > 세 값)
4. 결정과 이유를 `선정_기록.md`에 남긴다. 결과를 본 뒤 기준을 바꾸면 그 이유도 남긴다
