# 팀 분석 결과

이 폴더에 군집화 실험, 문항 태깅 결과, 분석 보고서 등을 저장할 수 있다.

분석별 폴더를 만들고 아래 내용을 함께 기록하면 다른 팀원이 결과를 재현하기 쉽다.

- 사용한 전처리 데이터의 버전 또는 커밋.
- 대상 지식과 포함·제외 조건. 예: 풀이 수, 서로 다른 문항 수, 무응답 처리.
- 사용한 특징과 각 비율의 분모, 표준화·결측 처리 방법.
- 원본 채점과 재채점 중 무엇을 사용했는지, 재풀이를 포함했는지.
- 실행 명령, 필요한 패키지 버전, 난수 시드, 결과 해석의 한계.

전처리 결과를 바꾸어 실험할 때는 원본 결과 파일을 덮어쓰는 대신 이 폴더에 실험용 사본과 변환 코드를 저장한다. 공통 전처리 규칙을 수정할 때는 `../코드`의 코드·수작업 기준을 함께 갱신하고 검증한다. 이 안내는 분석 범위를 제한하는 규칙이 아니라 결과를 서로 이해하기 위한 기록 권장사항이다.
